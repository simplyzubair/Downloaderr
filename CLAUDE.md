# Downloaderr (repo simplyzubair/Downloaderr, public, default branch main)

- Windows download manager (Electron) + browser extension. Rebranded from the MIT project Awesome Downloader; keep its LICENSE copyright line.
- Internal IDs keep the old name on purpose (data folder `~/.awesome-downloader`, native host `com.awesome.downloader`, appId `com.awesomedownloader.desktop`, Firefox ID, NSIS registry keys). Renaming them breaks existing installs and the extension.
- Releases: every push to `main` (not `*.md`, `docs/`, `website/`, `deploy/`) builds `v0.2.<run>`; it publishes only after the `release` environment is approved via `.github/workflows/release.yml`. Owner rule (2026-11-04): the agent approves it itself (`gh api -X POST repos/simplyzubair/Downloaderr/actions/runs/<id>/pending_deployments`) once the windows and mac jobs and Windows tests are green and nothing looks risky; otherwise it does not approve and tells the owner. Only one release run builds at a time; cancel an older waiting run when a newer push contains its changes. Installed apps download it in the background and show "Update now" (sidebar card + tray). Never hand-tag.
- Website: https://downloaderr.skillsgeek.com, `bash scripts/deploy-website.sh` (host nginx on `co`, `/var/www/downloaderr`, certbot HTTPS, Cloudflare DNS only).
- Before every push: `npm test` (122+ tests). For release-workflow changes, push a branch and `gh workflow run release.yml --ref <branch>` (builds without publishing); merge to `main` only when green.
- In this T3 shell `ELECTRON_RUN_AS_NODE=1` is set; unset it before launching Electron. Screenshot harness lives in `D:\Backups\rebrand-scripts\shot`.
- Browser extension (owner decision, 2026-11-04): keep the upstream Chrome Web Store listing `dnolinbkicmedadaigcedkmndcpahmml` (old "Awesome Downloader Integration" name/logo, owned by the original author) so auto-install keeps working for free. Do not remove its trust or the installer's store step. Own branding in the store would need a $5 Chrome listing or a free Edge Add-ons listing.
