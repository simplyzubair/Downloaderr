Install on Windows

  1. Run the installer. If Windows warns you, click More info → Run anyway.
  2. Open Downloaderr and click Browser extension to connect your browser.
  3. New versions download by themselves. Click Update now when it appears.

Install on Mac

  1. Open the .dmg and drag Downloaderr into Applications.
  2. The Mac app is not signed by Apple, so macOS blocks the first start. Open System Settings → Privacy & Security, scroll down and click Open Anyway.
  3. If macOS says the app is "damaged", run this once in Terminal: xattr -dr com.apple.quarantine /Applications/Downloaderr.app
  4. When a new version is out, Downloaderr shows a Download button that brings you back here.

Install the browser extension

  1. Install the Downloaderr app first. Its Browser extension window also has this extension ready (it updates with the app).
  2. Or unzip this download into a folder you will keep.
  3. Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the Downloaderr-Extension folder.
  4. In Downloaderr, open Browser extension and click Refresh. Each new site asks once before Downloaderr takes its downloads.
